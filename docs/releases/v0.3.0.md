Packmule no longer carries any of its old ResourcePackButler names.

## Changed

- **Removed** the `/butler`, `/resourcepackbutler` and `/rpb` commands, the `resourcepackbutler.*` permissions, and the copy of `plugins/ResourcePackButler/` into `plugins/Packmule/` on first start.
- **Pack IDs** now start with `packmule:pack:` instead of the old namespace. Clients see these IDs, so **every player downloads each pack once more** after this update. After that, nothing changes.

## Upgrading

Replace the jar and restart. If a server still grants the old `resourcepackbutler.*` permission nodes, grant `packmule.*` instead (`packmule.recheck`, `packmule.reload`, `packmule.status`, `packmule.pack.set`, `packmule.notify`). Nothing else is needed.

## Tested

40 unit tests pass. The unit test for pack IDs checks the new namespace. The bot test suite on a Paper server was updated to match but has not been run for this release, and nothing has been seen in a real game client.
